# Content Guidelines

## Age Bands

### Ages 3-5

- Prefer short sentences.
- Use simple, concrete vocabulary.
- Introduce one idea per page when possible.
- Repetition and rhythm are useful.
- Keep numbers rare unless they are especially fun or memorable.

### Ages 6-8

- Use slightly longer sentences.
- Include more explicit factual detail.
- Use `extras` for optional numbers, comparisons, or short side facts.
- Keep the main text readable aloud.

## Tone

- Warm, clear, and factual.
- Make the topic fun and interesting.
- Avoid sounding like a textbook.

## Fact Handling

- Every factual claim must trace back to the research notes or sources in `content.json`.
- If a fact is uncertain, omit it.
- If the source wording is too advanced, simplify without changing the meaning.
- When facts are scary or gross, reduce detail for younger readers.

## Page Writing

- `text` is the main read-aloud copy.
- `extras` are optional small callouts.
- Avoid crowding too much text onto a single page.
- Vary pacing so some pages can breathe.

## Image Use

- Pick images that are visually legible to children.
- Avoid repetitive near-duplicates.
- Use multiple images on a page only when they help comparison or variety.
- Every image needs alt text.
